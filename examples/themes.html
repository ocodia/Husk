Semantic choices

The forest brand overrides action, link, selection and header colors for both light and dark modes. Shared surfaces, readable text and focus styles remain coordinated.

<html data-brand="forest" data-theme="dark">

<link rel="stylesheet" href="css/husk.css">
<link rel="stylesheet" href="themes/forest.css">

Read the theme contract for reference scales, semantic states, local geometry and token inheritance.

What still needs manual review?

Native control popups, forced colors, zoom, text spacing and screen-reader behavior require platform testing. Changing theme tokens is not an automatic accessibility certification.

Action variants

Buttons keep their native behavior. These appearance previews change no project data. Use one primary action per task group and label destructive actions clearly.

<button type="submit">Save project</button>
<button type="reset" data-variant="secondary">Reset answers</button>
<button type="button" data-variant="quiet">Clear filters</button>
<button type="button" data-variant="danger">Delete draft</button>

Shared control sizes

Size is an opt-in on the native control. Small keeps 1rem text and a 2.5rem minimum target; default preserves the existing comfortable sizing; large has a 3.5rem minimum. Content can grow without being clipped.

Shared state colors

Static color samples use semantic text, background and border tokens. Their headings explain the state without relying on color. These samples are application CSS; callout, badge and toast components remain planned.
